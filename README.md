# QA Companion Standalone Bot

บอทตัวนี้จะทำหน้าที่ดึงข้อมูลจาก OpenProject และส่งเข้า Discord ตลอด 24 ชั่วโมง โดยไม่ต้องเปิดหน้าเว็บทิ้งไว้ครับ

## วิธีการใช้งานในเครื่องตัวเอง (สำหรับการทดสอบ)

1. ต้องมี **Python** ติดตั้งในเครื่อง (ถ้ายังไม่มี โหลดได้ที่ python.org)
2. เปิด Command Prompt (หรือ Terminal) แล้วพิมพ์คำสั่งเพื่อติดตั้งไลบรารีที่จำเป็น:
   ```bash
   pip install requests
   ```
3. เปิดไฟล์ `bot.py` ขึ้นมาด้วย Notepad หรือโปรแกรมแก้โค้ด
4. นำ **API Token** ที่คุณสร้างจากเว็บ OpenProject ไปใส่ในบรรทัดที่ 10 ตรงคำว่า `"YOUR_API_TOKEN_HERE"`
5. รันบอทด้วยคำสั่ง:
   ```bash
   python bot.py
   ```
6. ถ้าระบบขึ้นว่า `🚀 Standalone Discord Notifier Bot is starting...` แปลว่าสำเร็จ บอทเริ่มทำงานแล้ว! (เปิดหน้าต่างดำๆ นี้ทิ้งไว้ได้เลย)

## วิธีนำไปรันบน Cloud ฟรี (เพื่อให้ทำงานตอนปิดคอมได้)

หากต้องการให้มันทำงานตอนปิดคอมด้วย แนะนำให้นำไฟล์ `bot.py` และ `requirements.txt` (สร้างไฟล์นี้แล้วพิมพ์คำว่า `requests` ลงไปบรรทัดเดียว) 
นำไปฝากไว้บนเว็บให้บริการ Cloud ฟรี เช่น **Render.com** หรือ **Railway.app** 

เมื่อนำโค้ดขึ้นไปบนบริการเหล่านี้แล้ว เซิร์ฟเวอร์ของพวกเขาจะทำการรันสคริปต์นี้ให้คุณตลอด 24 ชั่วโมงโดยที่คุณปิดคอมพิวเตอร์ไปได้เลยครับ!
